# Политика конфиденциальности

`pinterest-wallpaper` — личное приложение для рабочего стола. Оно работает только на компьютере владельца и показывает его пины с Pinterest как обои.

- Токены доступа и cookie хранятся локально в `~/.config/pinterest-wallpaper/auth.json` (права файла `0600`).
- Картинки кэшируются локально в `~/.cache/pinterest-wallpaper/`.
- Данные никому, кроме API Pinterest, не передаются.
- Аналитики и сторонних трекеров нет.
- Приложение не публикует пины и не меняет аккаунт.

Чтобы удалить сохранённые данные, выполни `pinterest-wallpaper logout` и удали каталоги `~/.config/pinterest-wallpaper` и `~/.cache/pinterest-wallpaper`.
